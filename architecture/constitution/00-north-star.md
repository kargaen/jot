# 0. North Star

*Human-authored (braindump by the project owner, 2026-07-12; transcribed verbatim as
confirmed). Constitution — agents cite this section, never edit it.*

**Jot is the assistant that follows you around without getting in the way.**

The one property this architecture protects: **attention is opt-in, capture is not.**

1. **Capture is never more than a moment away.** On every surface — desktop, mobile,
   widget — the path from thought to saved task must stay instant and natural-language.
   No feature, layer, or dependency may sit between the user and capture.

2. **Jot decides what to show by the user's context, never by its own urgency.**
   What is visible is always filtered by the user's chosen contexts — which spaces,
   on which device, at which times. Work must be silenceable at home; chores must be
   silenceable at work. A feature that forces global attention fails this test.

3. **Planning stays at the effort altitude, not the hour altitude.** Jot warns early
   when a day holds too much — scrum-style effort, not micromanaged time-tracking.
   Overviews (lists, Pulse) and subtle completion rewards keep it calm, never managerial.

A change that makes Jot louder, slower, more intrusive, or more managerial deviates from
this north star even when it is individually useful — name the deviation in the epic's §5.
